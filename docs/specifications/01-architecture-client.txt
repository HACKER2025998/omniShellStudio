3. Module 1 : Command Intelligence Vault & Rétro-Ingestion Historique
Ce module est le cœur quotidien de l'application. Dès la première installation (via apt, yay, .deb, .bin ou .exe) et avant même que l'utilisateur ne tape une nouvelle commande, le logiciel fouille automatiquement le système pour récupérer, nettoyer, dédupliquer et classer toutes les commandes tapées par le passé.
3.1. Moteur de Rétro-Ingestion Automatique au Premier Lancement (First-Run Backfill)
Au démarrage du daemon Rust, le thread d'ingestion scanne les chemins suivants selon l'OS détecté :
Système / Shell
Chemins des Fichiers d'Historique Scannés
Format de Parsing & Particularités Gérées
Linux / macOS - Zsh
~/.zsh_history, ~/.zhistory, $HISTFILE
Gère le format étendu `: 1728900000:0;sudo pacman -Syu` (extraction du timestamp Unix et de la durée) ainsi que les lignes multi-lignes avec antislash `\`.
Linux / macOS - Bash
~/.bash_history
Gère le format standard ligne par ligne ainsi que les lignes de timestamp `#1728900000` lorsque HISTTIMEFORMAT est activé.
Linux / macOS - Fish
~/.local/share/fish/fish_history
Parse la structure pseudo-YAML de Fish (`- cmd: ...`, `  when: ...`, `  paths: ...`) pour extraire la commande exacte, la date et les chemins utilisés.
Windows - PowerShell
%APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
Lit l'historique persistant de PSReadLine (PowerShell 5.1 et PowerShell 7+), gère l'encodage UTF-8/UTF-16LE et les backticks de continuation.
Terminaux Émulés
kitty, Alacritty, GNOME Terminal, Konsole, Windows Terminal, WezTerm
Détecte l'émulateur parent via l'arbre des processus ($TERM_PROGRAM, PPID) lors de la capture en temps réel et l'associe à chaque commande.

3.2. Capture Temps Réel des Nouvelles Commandes (Shell Hooks Non-Intrusifs)
Lors de l'installation du paquet, OmniShell Studio injecte un hook ultra-léger (temps d'exécution < 1.5 milliseconde, asynchrone en arrière-plan pour ne jamais ralentir le prompt) dans ~/.bashrc, ~/.zshrc, ~/.config/fish/config.fish et $PROFILE (PowerShell). À chaque validation d'une commande (preexec / precmd), le hook envoie via un Socket Unix local (/tmp/omnishell.sock sur Linux/macOS) ou un Named Pipe (\\.\pipe\omnishell sur Windows) un paquet JSON contenant :
PAYLOAD JSON DU SHELL HOOK TEMPS RÉEL{  "raw_command": "sudo docker run -d -p 8080:80 --name web-nginx nginx:alpine",  "working_directory": "/home/bernard/projects/glpi-stack",  "shell": "zsh",  "terminal_emulator": "kitty",  "exit_code": 0,  "duration_ms": 1420,  "timestamp": 1760515440}

3.3. Algorithme AST de Normalisation, Détection Sudo et Catégorisation Automatique
Le problème majeur des gestionnaires d'historique classiques est qu'ils classent `sudo docker ps` sous `sudo` au lieu de `docker`. Le moteur Rust d'OmniShell Studio exécute un pipeline lexical en 5 étapes :
Étape 1 (Détection et Extraction des Wrappers de Privilèges) : Si la commande commence par `sudo`, `doas`, `pkexec`, `su -c`, `nohup`, `time`, `watch` ou `env VAR=val`, le parseur active le booléen `is_privileged = true` (qui affichera un badge ambre [SUDO] dans l'UI) et extrait le véritable binaire cible qui suit.
Étape 2 (Identification du Binaire Racine & Sous-Commande) : Pour `sudo docker compose -f prod.yml up -d`, le binaire racine est `docker` et la sous-commande est `compose up`. Pour `ip -c addr show wlan0`, le binaire racine est `ip` et la sous-commande est `addr`.
Étape 3 (Classification Taxonomique en 12 Grandes Catégories & 50+ Sous-Sections) : Chaque binaire est rattaché à une arborescence claire affichée dans la Sidebar gauche :
Catégorie Principale (Sidebar)

4. Module 2 : Snapshot Offline Docker & Infrastructure + DBA/UML Studio
L'utilisateur veut pouvoir consulter tous ses conteneurs Docker (actifs ou anciens), leurs ports, leurs volumes et les commandes exactes qui ont servi à les lancer, même lorsque le démon Docker est éteint ou qu'il n'a aucune connexion Internet pour demander de l'aide à une IA.
4.1. Synchronisation Continue & Cache Offline des Conteneurs Docker
Connexion au Socket Local : Le backend Rust écoute en continu `/var/run/docker.sock` (Linux/macOS) ou `//./pipe/docker_engine` (Windows) dès que Docker est actif.
Snapshot SQLite Persistant : Chaque fois qu'un conteneur démarre, change d'état ou est créé, OmniShell Studio sauvegarde dans la table `docker_containers_cache` : l'ID du conteneur, son nom, l'image, les ports mappés (ex: `0.0.0.0:8080->80/tcp`), les volumes montés (`HostPath -> ContainerPath`), le réseau Docker, les variables d'environnement non-sensibles, les 200 dernières lignes de logs et surtout la commande `docker run` ou le fichier `docker-compose.yml` exact qui l'a généré.
Consultation 100% Hors-Ligne (Sans Internet ni IA) : Dans l'onglet « 🐳 Docker & Infra », l'utilisateur voit la grille de tous ses conteneurs sous forme de cartes blanches élégantes. En cliquant sur un conteneur (ex: `glpi-app` ou `postgres-db`), le Tiroir d'Inspection (Zone D) affiche instantanément un générateur d'actions prêtes à copier en 1 clic :

6. Module 4 : ClassShare LAN — Serveur de Partage de Fichiers & Dossiers Sans Internet
Conçu spécifiquement pour les salles de classe, les travaux pratiques universitaires, les réunions techniques ou les interventions sur site sans connexion Internet. Un enseignant (« Maître / Host ») ou un chef de projet partage des fichiers ou des dossiers entiers sur le réseau local en quelques secondes, avec un contrôle total des permissions.
6.1. Parcours Utilisateur Complet du « Maître » (Host) et des « Pairs » (Étudiants/Collègues)
1. Création de la Salle par le Maître : Dans l'onglet « 📂 ClassShare LAN », le Maître glisse-dépose un fichier ou un dossier complet (ex: `TP_Reseau_CCNA.zip` ou un dossier `Cours_Laravel/`). Le backend Rust compresse à la volée les dossiers en flux streaming `.tar.zst` ou les expose en arborescence directe, démarre un serveur Axum HTTP/2 + WebSockets sur un port dynamique (ex: `0.0.0.0:49152`) et annonce la session via mDNS (`_omnishell-share._tcp.local.`).
2. Génération Automatique du Code à 6 Chiffres & du QR Code : L'interface affiche immédiatement en grand un Code PIN à 6 chiffres (ex: `482 - 915`) et un QR Code haute densité. Le code à 6 chiffres encode de manière déterministe le dernier octet (ou les deux derniers octets) de l'IP locale du Maître + un jeton de session HMAC de 3 chiffres, permettant aux autres instances d'OmniShell Studio de trouver le serveur même si le routeur de l'école bloque le multicast mDNS !
3. Connexion des Pairs (Avec ou Sans l'Application Installée) : • Si l'étudiant possède OmniShell Studio : il clique sur [Rejoindre une Salle], tape les 6 chiffres `482915`, et accède instantanément à l'explorateur de fichiers partagés.• Si l'étudiant est sur un téléphone (iPhone/Android) ou un PC sans l'application : il scanne le QR Code et accède à une interface Web embarquée ultra-rapide (servie directement par le binaire Rust du Maître, sans Internet) où il saisit le code PIN pour télécharger ou téléverser des fichiers.

Coupe la connexion WebSocket, invalide le jeton de session et bloque toute requête HTTP provenant de son couple (IP, Fingerprint) pour la session en cours.

6.3. Déconnexion / Reconnexion Transparente & Reprise de Transfert (Resumable Chunking)
Si un utilisateur ferme son ordinateur, perd le Wi-Fi temporairement ou clique sur [⏸️ Quitter temporairement], puis revient 15 minutes plus tard :
Persistance du Jeton de Session : L'application conserve en SQLite le `session_token` et l'empreinte cryptographique Ed25519 du pair. Dès que le réseau est rétabli, OmniShell Studio se reconnecte automatiquement au Maître sans redemander le code à 6 chiffres et restaure ses permissions exactes (y compris son droit d'upload si le Maître le lui avait accordé).
Transferts Découpés en Blocs (Chunked HTTP Range + BLAKE3) : Les gros fichiers (ex: ISO Linux de 4 Go ou VM VirtualBox) sont découpés en blocs de 4 Mo vérifiés par hachage BLAKE3. Si la connexion coupe à 67%, la reconnexion reprend exactement au bloc suivant via l'en-tête `Range: bytes=...` sans perdre un seul octet.

8. Gestion Exhaustive des Cas d'Exception & Résilience
Le logiciel ne doit jamais crasher ni afficher d'écran blanc. Chaque cas limite système ou réseau est intercepté par un type `Result<T, OmniError>` en Rust et traduit en action corrective claire dans l'interface :
Code d'Exception
Scénario Déclencheur
Comportement de Repli (Fallback) & Message UI
ERR_HIST_CORRUPT
Fichier .zsh_history ou .bash_history contenant des octets non-UTF8 (binaire corrompu).
Utilisation de `String::from_utf8_lossy` ligne par ligne. Les lignes corrompues sont ignorées sans bloquer l'importation des 15 000 autres commandes.
ERR_RAW_SOCKET_PERM
L'utilisateur lance un scan NetMap sur Linux sans les capacités `CAP_NET_RAW` pour l'ARP/ICMP.
Bascule automatique et transparente en mode « Unprivileged TCP Connect + Lecture Table ARP Noyau (`/proc/net/arp`) + mDNS » et affiche une bannière douce proposant d'activer `setcap cap_net_raw+ep` en un clic.
ERR_DOCKER_OFFLINE
Le service `docker.service` ou Docker Desktop est arrêté.
Affiche un badge « 🟠 Mode Snapshot Hors-Ligne : Consultation du cache local » et permet quand même de parcourir tous les anciens conteneurs et de copier leurs commandes.
ERR_MDNS_BLOCKED
Le Wi-Fi de l'école ou de l'entreprise bloque le multicast UDP 5353 (Client Isolation partiel).
Le code à 6 chiffres encode directement l'adresse IP locale et le port du Maître en Base-10 compactée : la connexion directe TCP fonctionne donc à 100% sans mDNS.
ERR_DISK_QUOTA
Un étudiant autorisé tente d'envoyer un fichier de 50 Go qui saturerait le disque du Maître.
Vérification préalable de l'espace libre via `sysinfo` + limite configurable par le Maître (par défaut : 2 Go max par fichier). Rejet HTTP 413 immédiat avec notification claire.

9. Packaging & Distribution Multi-Plateforme (apt, yay, .deb, .bin, .exe)
Arch Linux (AUR - yay / paru) : Deux paquets maintenus : `omnishell-studio` (compilation depuis les sources Rust/Node) et `omnishell-studio-bin` (installation instantanée en 5 secondes depuis le binaire pré-compilé). Le script `post_install` configure automatiquement `setcap cap_net_raw,cap_net_admin+eip /usr/bin/omnishell` pour éviter d'avoir à lancer l'application en root lors des scans réseau.
Debian / Ubuntu / Kali / Mint (apt & .deb) : Paquet `.deb` officiel généré par `cargo tauri build --bundles deb` + dépôt APT signé par clé GPG (`deb [signed-by=/etc/apt/keyrings/omnishell.gpg] https://apt.omnishell.dev stable main`).
Binaire Portable Linux (.bin / AppImage) : Fichier unique exécutable sans droits root pour tout serveur ou poste de TP restreint.
Windows 10 / 11 (.exe NSIS / .msi / winget) : Installateur `.exe` signé qui ajoute l'entrée au menu Démarrer, enregistre la règle de pare-feu Windows pour le partage LAN et installe le hook dans le profil PowerShell.
